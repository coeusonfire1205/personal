How do I put this on Vercel?
  1. Download the ZIP, then extract it.
  2. Create a GitHub repository and upload the extracted files and the assets folder. The index.html file should be at the root.
  3. In Vercel, choose Add New → Project and import that repository.
  4. Set Framework Preset to Other. Leave Build Command empty and use . as the Output Directory.
  5. Deploy, open the live link on your phone to check it, then send it to her. 🌻

For larger videos that GitHub’s upload page won’t accept, use Git locally or put the video on a host that provides a direct HTTPS video URL and set that URL in config.js. The README includes a Vercel CLI option too.

The site is excluded from search indexing, but anyone with its URL can open it. Only include media you’re comfortable sharing that way.
